Statistics Tools: t-Test, ANOVA & Regression

This add-on brings the classic data analysis tools to Google Sheets™: descriptive statistics, correlation, covariance, rank and percentile, regression, t-tests, F-test, ANOVA and histograms. Select your data with its headers, pick a tool, and the result appears in a new sheet as a finished table with the same rows and labels as the classic add-in (Analysis ToolPak), in six languages. Free, one permission.

How to use it

  1. Select your data with the headers in the first row.
  2. Open the Extensions menu, find Statistics Tools and pick the tool. The table appears in a new sheet named after the tool; results are fixed values, so change the data and run the tool again when needed.
  3. No data yet? Create example sheet, in the same menu, adds sample columns ready to analyse (Score; Group A, B, C; x, y).

The tools and what to select

  • Descriptive statistics, Correlation, Covariance, Rank and percentile: one or more columns.
  • Regression: the first column is Y, the others are X (one or several). Output: Multiple R, R Square, Adjusted R Square, Standard Error, Observations, ANOVA table, coefficients with standard error, t Stat, P-value and 95% limits.
  • t-Test: paired two sample, two-sample assuming equal variances, two-sample assuming unequal variances (two columns), and one sample against a value you type (one column). The unequal-variances test rounds the degrees of freedom to a whole number, as the classic add-in does; the exact Welch value is in a note on that cell.
  • F-Test two-sample for variances: two columns.
  • ANOVA: single factor (one group per column); two-factor without replication (row labels in the first column, column labels in the first row); two-factor with replication (same layout, blocks of equal size, you type the rows per sample; balanced design).
  • Histogram: one column (automatic bins: about √n equal classes between the minimum and the maximum, upper limits included, plus a “More” row), or two columns to use your own bin limits; Pareto order available; a column chart is added next to the table.

Details that matter

  • Blank cells and text are ignored. Correlation, covariance and the paired t-test use only the rows where both cells are numbers, so pairs stay aligned.
  • Sample variance (n−1); kurtosis and skewness as in the classic add-in; confidence level with Student’s t; alpha is 0.05 (95%), and the P-values let you judge any other level.
  • With too few values a cell shows #DIV/0!, as in the classic add-in. Linearly dependent X columns stop the regression with a clear message.
  • Checked against published reference values: t and F critical values, Anscombe’s quartet (slope 0.5001, R Square 0.6665, F 17.99), a known ANOVA (F = 2, P = 0.178).
  • Not included yet: z-Test, moving average, sampling, exponential smoothing, random number generation, Fourier analysis.

Languages

The menus, the tables and the messages follow the language of your Google account: English, Spanish, Portuguese, French, German and Italian, with the labels of the classic add-in in each language. Any other language shows English.

Questions

Does anything leave my spreadsheet?
No. The add-on is a script that runs inside your Google account and only asks for permission to edit the spreadsheet it is open in. No servers of ours, no tracking, no account. See the privacy policy.
Will the numbers match the classic add-in?
Yes for the same data: the formulas are the standard ones and the layout is the same. Statistical software that uses fractional degrees of freedom (R, Python) can differ in the third decimal of the P-value of the unequal-variances t-test.
Can I undo?
Each run creates a new sheet; delete it, or use Ctrl+Z (Cmd+Z on Mac).
Does it work in the mobile app?
No. Google Sheets™ add-ons run in the web version only.
