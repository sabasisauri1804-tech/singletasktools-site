Rows to Calendar: Create Events from a Spreadsheet

An add-on for Google Sheets™ by Single Task Tools. One task: turn the rows of a spreadsheet into Google Calendar™ events in one run, weekly repeats included, into a calendar of its own. Menus in English, Spanish, Portuguese, French, German and Italian.

Install it from the Google Workspace Marketplace™ (search for “Rows to Calendar”), or from Extensions › Add-ons › Get add-ons inside Google Sheets™.

How to use it

  1. Write your column names in the first row: Title, Start date, Start time, End date, End time, Description, Location, Guests, Repeat, Until (in any of the six languages; only Title and Start date are required). Short names like Date, Time, Event or Where work too. No Title column? The add-on asks which column to use and remembers it.
  2. Open Extensions › Rows to Calendar › Add events (all rows, or only the rows you select).
  3. The events appear in a calendar called “Events from <your sheet>” inside your Google Calendar™, next to your other calendars: one calendar per spreadsheet file, or one per tab if you prefer (Options). Rename it, share it with your team, tick it on your phone. Two columns are added to the sheet, Event ID and Event link.

Privacy first

The add-on asks for one calendar permission only: to create calendars of its own and manage the events in them. It only sees the calendars that this add-on created: your main calendar and your other calendars, yours or shared with you, stay invisible to it and untouched. Putting events straight into an existing calendar needs a wider Google permission; a version with that option is planned.

What you can do

  • Update: change anything in the sheet and choose Update events (all rows with an ID, or the selected rows); each event is rewritten from its row, nothing is duplicated. One way: the sheet is the source.
  • Delete: select rows and delete their events; the ID column is cleared. Run it twice by mistake and nothing is duplicated.
  • Repeating events: a Repeat column (daily, weekly, monthly) and an Until column with the last date. One row = the whole series.
  • All-day events: leave the time cells empty. If the end is missing, the event lasts one hour.
  • Dates and times as your sheet shows them, in the spreadsheet’s time zone. The first time, the add-on shows you that time zone and the time it is there right now, and asks you to confirm it before it creates anything; if it is not yours, you change it in File › Settings and try again. Dates typed as 3/11/2026 follow your sheet’s regional format (File › Settings › Locale); 2026-11-03 is never ambiguous.
  • Guests: a column with email addresses adds them as guests. Invitation emails go out only if you turn them on in Options.
  • Create example sheet adds a week of classes to try it before touching your own data. Up to 120 rows each time you run it; with more rows, run it again and it continues.

Questions

Can two people use it in the same spreadsheet?
The calendar lives in the Google account that created it. When another person opens the same spreadsheet with their own account and uses the menu, the add-on does not find that calendar there, and it asks before doing anything: Cancel leaves everything as it was. For that person to add, update and delete events from their account too, the owner of the calendar shares it with them in Google Calendar™ with the permission “Make changes and see all event details”. A permission that only lets them see the events is not enough, and some organisations do not allow giving that permission to people outside the organisation. To see the events, sharing the calendar in the usual way is all it takes.
I made a copy of my spreadsheet. What happens with the events?
The copy keeps the Event ID and Event link columns, but those events stay in the calendar of the original spreadsheet. In the copy, Update does not find them: it creates them again in a new calendar named after the copy and tells you how many, and they count as created events. Delete only clears their Event ID in the copy, and says so; the events of the original are not touched. To start the copy from scratch, clear its Event ID column and choose Add events.
