Image Resizer: Fit to Page, Same Width & Scale

A free add-on for Google Docs™ by Single Task Tools. One task: resize all the pictures of a document at once, or only the selected ones, keeping their proportions: fit the wide ones to the page, give every picture the same width or the same height (in cm, inches or pixels) or scale them by a percentage. Also inside tables. Menus in English, Spanish, Portuguese, French, German and Italian.

Install it from the Google Workspace Marketplace™ (search for “Image Resizer”), or from Extensions › Add-ons › Get add-ons inside Google Docs™.

How to use it

  1. Open your document and go to Extensions › Image Resizer.
  2. To change only some pictures, select them first (or the paragraphs or table cells that contain them); with nothing selected, every picture of the document is changed. Choose Fit pictures to the page width (shrinks the pictures that stick out of the page or the margins; smaller ones are left alone), Same width for all pictures or Same height for all pictures (type a size such as 12 cm, 4 in or 600 px) or Scale pictures (type a percentage, such as 50).
  3. Done: the message tells you how many pictures changed and their new size. Ctrl+Z (Cmd+Z on a Mac) undoes the whole run.

Worth knowing

  • With nothing selected, all the pictures of the document are resized: inline pictures, pictures anchored to the text (Wrap text or Break text), pictures inside tables and in the header and footer. Select one or more pictures (or the paragraphs that contain them) to change only those.
  • Each picture keeps its current proportions, so nothing is squashed or stretched. No picture is made wider or taller than the text area between the margins (to go wider, reduce the margins in Page setup first), and a picture inside a table is never made wider than its column, also next to merged cells; the message says when a size was capped. Same height is the one for photo grids: pictures side by side in a table row line up even when some are portrait and some landscape.
  • Only the displayed size changes, like dragging a corner handle: the picture keeps its full quality, so you can make it larger again later. The document does not get lighter: nothing is compressed.
  • Picture sizes lists the current size of every picture in pixels, cm and inches, and the width of the page between the margins. Insert example pictures adds three pictures of different sizes (one wider than the page) to try it on any document.
  • Type the unit you like: cm, mm, in or px. A number without a unit means centimetres, or inches when your Docs™ is in English; the question always says which. The last size or percentage you used is shown the next time. In a document with several tabs, the open tab is changed and the message says so. Up to 500 pictures per run (66 pictures took about a second).
  • Drawings made in Docs™ (Insert › Drawing) are not pictures and are left as they are.
  • Docs™ stores picture sizes in whole points (1/72 of an inch), so a size you type may be rounded by a fraction of a millimetre.

Questions

Does anything leave my document?
No. The add-on is a script that runs inside your Google account and only asks for permission to edit the document it is open in. No servers of ours, no tracking, no account; no image is uploaded anywhere. See the privacy policy.
Does it change the image files or the cropping?
No. It only changes the displayed width and height of each picture, like dragging a corner handle. The picture itself, its link and its alt text stay as they are.
Does it work in the mobile app?
No. Google Docs™ add-ons run in the web version only.
