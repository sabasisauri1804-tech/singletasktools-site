Image Resizer: Fit to Page, Same Width & Scale

A free add-on for Google Docs™ by Single Task Tools. One task: resize all the pictures of a document at once, keeping their proportions: fit the wide ones to the page, give every picture the same width (in cm, inches or pixels) or scale them by a percentage. Menus in English, Spanish, Portuguese, French, German and Italian.

Install it from the Google Workspace Marketplace™ (search for “Image Resizer”), or from Extensions › Add-ons › Get add-ons inside Google Docs™.

How to use it

  1. Open your document and go to Extensions › Image Resizer.
  2. Choose Fit pictures to the page width (shrinks the pictures that stick out of the page or the margins; smaller ones are left alone), Same width for all pictures (type a width such as 12 cm, 4 in or 600 px) or Scale pictures (type a percentage, such as 50).
  3. Done: the message tells you how many pictures changed and their new width. Ctrl+Z (Cmd+Z on a Mac) undoes the whole run.

Worth knowing

  • With nothing selected, all the pictures of the document are resized: inline pictures, pictures anchored to the text (Wrap text or Break text), pictures inside tables and in the header and footer. Select one or more pictures (or the paragraphs that contain them) to change only those.
  • Heights follow the widths, so nothing is squashed or stretched. A picture inside a table is never made wider than its column, and no picture is made wider than the page between the margins; the message says when a width was capped.
  • Picture sizes lists the current size of every picture in pixels, cm and inches, and the width of the page between the margins. Insert example pictures adds three pictures of different sizes (one wider than the page) to try it on any document.
  • A number without a unit is read as inches in English and as centimetres in the other languages; the question says which. The last width or percentage you used is shown the next time. Up to 500 pictures per run (66 pictures took about a second).
  • Docs™ stores picture sizes in whole points (1/72 of an inch), so a size you type may be rounded by a fraction of a millimetre.

Questions

Does anything leave my document?
No. The add-on is a script that runs inside your Google account and only asks for permission to edit the document it is open in. No servers of ours, no tracking, no account; no image is uploaded anywhere. See the privacy policy.
Does it change the image files or the cropping?
No. It only changes the displayed width and height of each picture, like dragging a corner handle. The picture itself, its link and its alt text stay as they are.
Does it work in the mobile app?
No. Google Docs™ add-ons run in the web version only.
