Document Maker: Invoices, Contracts & PDF per Row

An add-on for Google Sheets™ by Single Task Tools. One task: invoices, contracts, certificates, receipts and letters from your spreadsheet, one Google Docs™ file and one PDF per row, from a template you write once with <<Column>> tags, logo included. Menus in English, Spanish, Portuguese, French, German and Italian.

Install it from the Google Workspace Marketplace™ (search for “Document Maker”), or from Extensions › Add-ons › Get add-ons inside Google Sheets™.

How to use it

  1. Put the column names in the first row of your sheet (Client, Invoice no., Date, Amount…).
  2. Open Extensions › Document Maker › Create the template. A Google Docs™ file appears in your Drive with one tag per column. Write your document around the tags: text, headings, tables, bold, lists. Keep the exact column name inside the << >>.
  3. Generate documents (all rows, or only the rows you select). One row = one document: the add-on copies the template, replaces the tags with the values of that row, saves the Google Docs™ file and a PDF in a folder of your Drive named after the sheet, and writes the links in two new columns, Document and PDF.

What you get

  • Values exactly as they are shown in the cells: dates, currencies and numbers keep your sheet’s format.
  • File names from a pattern you choose, for example Invoice <<Invoice no.>> – <<Client>>.
  • Rows that already have a link are skipped: add rows and run it again without duplicates. Up to 80 documents each time you run it; if there are more, run it again and it continues where it stopped.
  • Images stay: the logo, signature or letterhead of the template appear in the Google Docs™ file and in the PDF.
  • To redo one row, delete its link and run it again. At the 101st free document the add-on stops and tells you.
  • Options: Docs only, PDF only or both. Create example sheet adds a sheet with invoices ready to try.

Questions

What does it access?
Only the spreadsheet that is open and the files it creates in your Drive: the template, the output folder, the documents and the PDFs. It cannot see your other documents or files, it sends no email and it has no server: your data stays in your Google account.
Does the PDF keep my logo and formatting?
Yes: the PDF is built from the document’s text, images, tables and formatting (headings, bold, italic, colours, lists, page breaks, header and footer), so the logo, signature or letterhead of the template appear in it. Drawings made inside Google Docs™ are not included; the Google Docs™ copy keeps everything.
Can it email the documents?
Not yet: this first version makes the files and writes their links in the sheet. Sending each document by email will come in a later version.
My invoices have several line items. Can one row hold them?
Not yet: one row makes one document. Put the line items in the template itself, or in one column (e.g. “Items”) with one item per line of the cell.
I already have a template document.
Create the template from the menu and paste the content of your document into it; the tags work anywhere in the text, headings and tables.
Does it work in the mobile app?
No. Google Sheets™ add-ons run in the web version only.
