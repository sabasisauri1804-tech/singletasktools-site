Randomize Slides: Shuffle Slide Order

This add-on puts the slides of a Google Slides™ presentation in a random order with one click: all of them, all but the title slide, or only the slides you select. It can keep pairs together (question + answer) or reverse the whole order. It is free.

How to use it

  1. Open the Extensions menu and find Randomize Slides.
  2. Pick Shuffle all slides, Shuffle all except the first slide, Shuffle the selected slides (select two or more in the filmstrip with Ctrl+click or Shift+click), Shuffle in pairs, Shuffle in pairs after the first slide or Reverse the order.
  3. Run it again for a new order, or press Ctrl+Z (Cmd+Z on Mac) to go back to the previous one.

What it takes care of

  • Nothing else changes: the slides keep their content, layouts, speaker notes, links and transitions. Only their order changes.
  • Shuffle in pairs keeps slides 1-2, 3-4, 5-6… together. If slide 1 is your title, use Shuffle in pairs after the first slide, which pairs 2-3, 4-5… and leaves the title first.
  • Skipped slides move like the others.
  • Tested with a 160-slide deck: the shuffle takes about one second.

Languages

The menus follow the language of your Google account: English, Spanish, Portuguese, French, German and Italian. Any other language shows English.

Questions

Nothing happened when I chose “Shuffle the selected slides”.
Select two or more slides in the filmstrip on the left (Ctrl+click or Shift+click) before running it. With one slide selected there is nothing to shuffle.
Can I undo?
Yes. One Ctrl+Z (Cmd+Z on Mac) puts the previous order back.
Does it work in the mobile app?
No. Google Slides™ add-ons run in the web version only.
What can it see?
Only the presentation you have open, and only while you use it. It reads the order of the slides and which ones you selected; it does not read their content. See the privacy policy.
